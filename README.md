# n8n Viewer

n8n Viewer — Drawflow-basierter Workflow-Editor und Viewer.

## Features

- Drawflow-based visual workflow editor
- Browse and search workflow templates (3,815+)
- Workflow node inspection and configuration
- Gallery view with category filtering
- Real-time workflow preview

## Tech Stack

JavaScript ES6+ · Drawflow · HTML5 Canvas

## Quick Start

```bash
git clone https://github.com/D-VKITZ/n8n-viewer.git
cd n8n-viewer
npm install
npm run dev
```
